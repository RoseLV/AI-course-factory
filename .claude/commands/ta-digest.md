Write the TA digest for: $ARGUMENTS

Check the course is `published` or `maintenance`. Run ta-agent in DIGEST mode. Render
`maintenance`, then run the checker through `published`. Summarise the digest in a few lines:
volume, escalations by category, top themes, and the suspected content defects. For each defect
propose which agent would fix it, and ask the human whether to open an improvement item. Do not
change approved content without that answer.
